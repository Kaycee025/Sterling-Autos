# Sterling Autos — Intelligent Luxury Car Sales Platform

A modern, responsive automotive sales and inventory discovery platform tailored for the Nigerian luxury and executive vehicle market.

## ✨ Features

- **Automated Sales Consultation & Matching**: Dynamic multi-criteria questionnaire matching buyers with ideal vehicles based on budget, purpose, body style, and powertrain.
- **Curated Luxury Inventory**: High-definition vehicle showroom showcasing flagship SUVs, executive sedans, and performance marques across Nigerian dealer hubs (Lagos, Abuja, Enugu).
- **Responsive & Premium Aesthetics**: Custom glassmorphism UI, typography, subtle micro-animations, and mobile-optimized layouts.
- **Multi-Page Experience**:
  - `index.html` — Showroom flagship homepage
  - `vehicles.html` — Full inventory browser with filters
  - `find-your-car.html` — Interactive vehicle finder consultation
  - `about.html` — Brand heritage and 150-point inspection standards
  - `contact.html` — Direct showroom contacts and private viewing scheduler
- **Local Application Server**: Built-in Node.js server (`server.js`) with static asset delivery and live market search API endpoints.

## 🚀 Getting Started Locally

### Prerequisites
- Node.js (v14 or higher)

### Run the Development Server
```bash
node server.js
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
